# Surya S — Software Developer Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Download and extract the ZIP file.
2. Open the `software_developer_portfolio` folder.
3. Open `index.html` in your browser.

For the best editing experience, open the folder in Visual Studio Code and use Live Server.

## Before publishing
1. In `index.html`, replace `your.email@example.com` with your email address.
2. In `script.js`, set `linkedinUrl` to your LinkedIn profile URL.
3. Check the GitHub links and project descriptions.
4. Add a `resume.pdf` file and a visible download link if you want recruiters to download your CV.
5. Check that every listed technology matches what you actually used and can explain in an interview.
6. Update internship descriptions to reflect the exact work you completed.

## Publish for free
You can publish this site with GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to provide the live website URL.
